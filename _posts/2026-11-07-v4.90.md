Parlatype 4.90 is an alpha preview of Parlatype 5.0. It is **not** recommended for daily use.

# What's new

Major changes are:
* Parlatype has its own text editor now.
* Consequently the LibreOffice extension is not supported anymore.  
  Actually it doesn't work with this version or future versions.
* Added support for whisper.cpp for better automatic transcription.  
  You can still use PocketSphinx.
* Automatic download of Whisper models.
* Removed help 😢  
  It was out-of-date for Parlatype 5.0 and removed to reduce maintenance burden.

## Translations

I'm happy to be on Hosted Weblate. Translation volume has been reduced by removing the LibreOffice extension and help pages.

This version is available on Flathub Beta and can be installed like this:

